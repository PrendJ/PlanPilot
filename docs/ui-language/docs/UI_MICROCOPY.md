# UI Microcopy

This file defines interface voice only, not product marketing tone.

## Voice

- concise;
- precise;
- human;
- slightly dry when appropriate;
- never cute at the expense of clarity.

## Rule

**Utility first, personality second.**

Good:
> No scenarios yet. Create one to compare forecast assumptions.

Optional Signature addition:
> Empty for now. Suspiciously peaceful.

Bad:
> Oopsie! Looks like your magical scenario universe is empty ✨

## Buttons

Use verbs:
- Create scenario
- Save changes
- Run forecast
- Compare
- Retry
- View details

Avoid vague:
- Continue
- Go
- Submit
when a more specific action is available.

## Errors

Structure:
1. what happened;
2. what the user can do.

Example:
> Forecast could not be generated. Check the date range and try again.

Do not blame the user.

## Success

Keep confirmations short:
> Scenario saved.

Do not celebrate routine actions excessively.

## Empty states

May include one dry secondary line after the useful explanation.

## AI/system content

Clearly label:
- generated;
- suggested;
- automated;
when relevant.

Avoid anthropomorphic certainty.

Good:
> AI suggestion
> Based on the last 12 weeks, demand may be underestimated.

Bad:
> I know demand will increase.

## Technical labels

Monospace uppercase labels can carry personality:

`SYSTEM / LIVE`
`WORKSPACE / ACTIVE`
`FILTER / 3 APPLIED`

Use them sparingly.
