# UI assets

## Visual asset direction

Prefer:
- technical line illustrations;
- diagrams;
- data-shaped graphics;
- UI fragments;
- clean product screenshots;
- abstract geometry derived from the interface grid.

Avoid:
- generic stock photography;
- random gradient blobs;
- 3D illustration packs unrelated to product;
- decorative assets behind mobile reading text.

## Empty states

Empty-state assets should be:
- simple;
- monochrome or one accent;
- understandable at small size;
- optional, never required to understand the state.

## Screenshots

When using product screenshots:
- show the actual product;
- avoid fake browser chrome unless needed;
- use consistent framing;
- dark/light examples should match supported themes.

## Icons

Use a single icon family per project.
Document any project-specific icon set locally.
